Glossario Tecnico: 345 Definizioni

1. Componenti Hardware

Tabella 1 CPU (Central Processing Unit)
Il "cervello" del computer che esegue le istruzioni dei programmi.
Tabella 2 RAM (Random Access Memory)
Memoria ad accesso casuale utilizzata per memorizzare i dati temporanei dei processi attivi.
Tabella 3 Scheda Madre (Motherboard)
Il circuito stampato principale che collega tutti i componenti del sistema.

2. Cavi e Porte

Tabella 50 USB-C
Standard di connessione reversibile per dati, video e alimentazione.
Tabella 51 HDMI
Interfaccia per il trasferimento di segnali audio/video digitali non compressi.
Tabella 52 RJ45 (Ethernet)
Connettore standard utilizzato per il cablaggio delle reti LAN.

3. Software e Sistemi Operativi

Tabella 100 Kernel
Il nucleo fondamentale di un sistema operativo che gestisce le risorse hardware.
Tabella 101 File System
Metodo di organizzazione e archiviazione dei file su un supporto di memoria.

4. Linguaggi di Programmazione

Tabella 150 Variabile
Area di memoria identificata da un nome che contiene un valore modificabile.
Tabella 151 Funzione / Metodo
Blocco di codice riutilizzabile che esegue una specifica operazione.

5. Reti e Sistemi

Tabella 250 Indirizzo IP
Identificativo numerico assegnato a ogni dispositivo collegato a una rete.
Tabella 251 DNS (Domain Name System)
Sistema che traduce i nomi di dominio leggibili dall'uomo in indirizzi IP.

6. Termini Vari

Tabella 300 Cloud Computing
Erogazione di servizi (server, storage, database) tramite Internet.
Tabella 345 Crittografia
Tecnica di cifratura dei dati per renderli incomprensibili a chi non ha la chiave.
